# rakazo.org

An independent blog about [Rakazo](https://github.com/elie222/rakazo), the open-source, self-hosted Grok Bot alternative.

Static site in `public/`, served by Cloudflare Workers static assets.

```bash
npx wrangler dev      # local preview
npx wrangler deploy   # deploy
```

Not affiliated with the Rakazo project.
