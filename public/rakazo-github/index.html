1. Find the official repo

Go to github.com/elie222/rakazo. "elie222" is the GitHub account of Elie Steinbock, who created Rakazo. Check these three things to be sure you're in the right place.

  1. The name reads elie222 / rakazo. Anything else is a copy.
  2. It has about 10,000 stars. Copies have only a handful.
  3. The About box links to rakazo.com, the official website.
Watch out for copies. Over 1,800 people have made their own copy of Rakazo, called a "fork". A fork shows forked from elie222/rakazo under its name. Forks can be out of date or changed, so download apps only from the official repo.

3. Download the desktop app

Ready-made apps for Mac, Windows and Linux are attached to each release. A new version comes out every few days.

Step 1: Open Releases

On the repo page, scroll down the right-hand column to Releases and click the version marked Latest. Or go straight to github.com/elie222/rakazo/releases/latest.

  1. Releases lists every version (28 so far).
  2. The newest version is marked Latest. Always pick this one.

Step 2: Check you're on the latest version

  1. Version number and the Latest badge. At the time of writing it's v0.16.0.
  2. Release date. Below it you'll find the release notes: what's new, fixed and changed.

Step 3: Download the right file

Scroll to the bottom of the release to Assets. There are 15 files, but you only need one.

  1. Mac: Rakazo-0.16.0-universal.dmg (265 MB). "Universal" means it works on both Apple silicon (M-series) and Intel Macs.
  2. Linux: Rakazo-0.16.0.AppImage (170 MB).
  3. Windows: Rakazo-Setup-0.16.0.exe (149 MB).
You can ignoreWhat it's for

Step 4: Install and choose a setup

  1. Mac: open the .dmg and drag Rakazo into Applications.
  2. Windows: double-click the .exe and follow the installer.
  3. Linux: make the file runnable with chmod +x Rakazo-*.AppImage, then open it.
  4. On first launch the app asks where Rakazo should run. Pick This computer to run everything locally, or Existing instance to connect to a server you already have.
Linux error about libfuse.so.2? Install the FUSE 2 library (libfuse2t64 on Ubuntu 24.04, fuse-libs on Fedora), or run ./Rakazo-*.AppImage --appimage-extract-and-run. This fix comes from the official README.

4. Download the Android app

The Android app has its own release, separate from the desktop versions. Open github.com/elie222/rakazo/releases/tag/android on your phone.

  1. Tap rakazo.apk (125 MB) to download it.
  2. You only install it once. After that it updates itself.

When you open the downloaded file, Android may ask you to allow installs from your browser. Allow it for this install, then open Rakazo and sign in to your server or the hosted app.

Looking for iPhone or iPad? That app isn't on GitHub Releases. Get it from the Download page on rakazo.com.

5. Run Rakazo on a server

You don't need to clone the repo to run Rakazo yourself. The README has a one-line installer that downloads everything it needs. You need Docker (with the Compose plugin), curl and OpenSSL installed first.

mkdir -p rakazo && cd rakazo &&
curl -fsSLO https://raw.githubusercontent.com/elie222/rakazo/main/infra/compose/install-images.sh &&
bash install-images.sh

When it finishes, open http://127.0.0.1:5173, create an account and connect a model. A server with 2 CPU cores and 4 GB of memory is enough, according to the README.

6. Clone or download the code

You only need the code if you want to change Rakazo or help build it. Click the green Code button on the repo page.

  1. Click Code to open the menu.
  2. Copy the clone address to download the code with Git.
  3. Or click Download ZIP to get a copy without Git. It won't update itself, so cloning is better for development.

To clone with Git, run:

git clone https://github.com/elie222/rakazo.git
cd rakazo
cp .env.example .env

To run the code you also need Node.js 24.15 or newer in the 24.x line (or 26+), pnpm 12 and Docker. Node.js 25 is not supported. After filling in the secrets in .env (the README explains each one), start it with pnpm install, pnpm sandbox:build and pnpm dev.

8. Stay up to date

Rakazo changes fast. Versions 0.13 to 0.16 all came out between 18 and 24 November 2026. Two clicks keep you informed. Both need a free GitHub account.

  1. Star the repo. Click Star at the top right. It saves the repo to your stars list so you can find it again.
  2. Get an email for each release. Click Watch (shown as Notifications when you're signed out), choose Custom, tick Releases and click Apply.

The desktop and Android apps update themselves, so you don't need to re-download them by hand. On a server, follow the official upgrading guide in the repo at docs/self-host-upgrading.md.

9. Get help and report bugs

Rakazo uses GitHub Issues for bugs and feature requests. Someone may already have your problem, so always search first.

  1. Search first. Type a word from your problem after is:issue, such as gmail or docker. Open and closed issues both show, and closed ones often contain the fix.
  2. No match? Click New issue. You'll need to sign in to GitHub.

When you click New issue, pick the form that fits:

FormUse it when
BugSomething in Rakazo doesn't work as it should
FeatureYou want something new added
Self-host setupRakazo won't install or start on your own machine or server

For setup problems, include the command you ran, the full error and your Rakazo version. If Rakazo starts, the form asks for this diagnostics report, which contains no secrets:

docker compose -f docker-compose.images.yml exec api node dist/cli/diagnostics.js
Never paste your .env file or API keys into an issue. Issues are public. For security problems, email security@rakazo.com and don't open an issue. For general questions, email support@rakazo.com or ask in the Rakazo Discord, which is linked from the README.

10. What the license lets you do

Rakazo uses the Apache-2.0 license, one of the most permissive open-source licenses.

You can

  • Use it for free, including for work and business
  • Change the code
  • Share your changed version

You must

  • Keep the LICENSE and NOTICE files when you share it
  • Say which files you changed
  • Not use the Rakazo name in a way that suggests it's official

FAQ

What is the official Rakazo GitHub repo?

It's github.com/elie222/rakazo. Other accounts that show a copy of Rakazo are forks.

Do I need a GitHub account to use Rakazo?

No. You can read the code, download the apps and run the installer without signing in. You only need an account to star the repo, watch for releases or open an issue.

Which file should I download for my Mac?

The file ending in -universal.dmg. It works on both Apple silicon (M-series) and Intel Macs.

Where is the iPhone app?

The iPhone and iPad app isn't on GitHub Releases. Get it from the Download page on rakazo.com.

What's the difference between the repo and rakazo.com?

The repo holds the code, app downloads and bug reports. rakazo.com is the official website with the hosted app, the docs and pricing.

How do I report a security problem?

Email security@rakazo.com. Don't open a public GitHub issue for security bugs.
