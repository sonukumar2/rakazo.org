Run your own AI teammates with Rakazo

Rakazo is the open-source, self-hosted alternative to Grok Bot: bots with their own memory, routines and computer, running on your machine with your model. This site explains how to install it, host it and use it well, in plain English.

01 · The basics

What is Rakazo?

Rakazo gives you persistent AI "bots" that work like teammates. Each bot has a job, remembers what it learns, runs on a schedule, and gets its own computer (a browser, terminal, files and a full desktop) inside a sandbox.

You bring the model: Claude, ChatGPT, OpenRouter, Grok, or a local model through Ollama or LM Studio. Each bot can use a different one.

  1. Get started: use the hosted app or run it yourself.
  2. Set up with your agent: copy a prompt and let your coding agent install it.
  3. Star count: the project is very active, with commits landing daily.

03 · Quick start

Install Rakazo in 3 steps

You need Docker Engine with the Compose plugin, curl and OpenSSL. No clone or Node.js install is required.

  1. Run the installer

    Make a folder, download install-images.sh and run it. It writes a .env with random secrets and starts everything with Docker Compose.

  2. Open the app

    Go to http://127.0.0.1:5173 and create your account.

  3. Connect a model

    Sign in with a Claude or ChatGPT plan, add an API key, or point it at a local model. Then create your first bot.

Want it always on? Run the same installer on a VPS with 2 vCPUs and 4 GB of RAM, put HTTPS in front of port 5173, and connect from the desktop or mobile app.

07 · FAQ

Common questions

Is Rakazo free?

Yes. The code is Apache-2.0 and free to self-host. You pay only for the model you use and any cloud sandbox or server you choose.

Can I use my Claude or ChatGPT subscription?

Yes. In model settings you can sign in with a Claude Pro/Max plan or an eligible ChatGPT plan, or connect an API key.

Can I run it fully offline with a local model?

Point a bot at any local OpenAI-compatible server such as Ollama or LM Studio. Each bot can use a different model.

Does it work on my phone?

Yes. There are apps for web, macOS, Windows, Linux, iPhone, iPad and Android, all talking to the same server.

Is this the official Rakazo site?

No. Rakazo Guide is an independent fan blog. The official project lives at rakazo.com and github.com/elie222/rakazo.
