What is Rakazo? A beginner's guide to the open-source AI bot

Rakazo lets you run your own team of AI helpers, called bots, that remember things, work on a schedule and use a computer just like you do. This guide explains it in plain words, with real screenshots.

Updated 27 Nov 2026 · 8 min read

The short answer

Rakazo is a free, open-source app for running AI bots that do real work for you. You give each bot a job, like "sort my email" or "prepare a morning briefing". The bot remembers what it learns, can work on a schedule, and has its own computer to click, type and browse with.

  • Free and open source. The code is public under the Apache-2.0 license.
  • Runs where you want. On your own computer, on a server, or in the hosted version.
  • Any AI model. Claude, ChatGPT, Grok, OpenRouter, or a free local model.
  • Works everywhere. Web, Mac, Windows, Linux, iPhone and Android.

Rakazo in one picture

This is the Rakazo app. If you've used a chat app, it will feel familiar. The difference is that each chat is with a bot that has a job and can actually do it.

  1. Your team of bots. Each bot on the left has its own job, such as Inbox Manager, Sales Outbound or Expense Manager.

Words you'll see

A few terms come up again and again. Here is what they mean.

Bot
An AI helper with one job, its own chats and its own memory. You can have as many as you like.
AI model
The "brain" a bot uses to think and write, for example Claude or ChatGPT. You choose it.
Computer
A safe, separate desktop where the bot clicks, types and browses. It can't touch the rest of your machine.
Routine
A task that runs by itself, such as "every weekday at 6am, tidy my inbox".
Self-hosted
You run Rakazo on your own computer or server, so you control the data and pay no subscription.
Integration
A connection to an app you use, such as Gmail, Slack, GitHub or Notion. MCP is a standard way to add more.
Approval
A check where the bot stops and asks you before doing something important, like sending an email.

Rakazo comes with ready-made bot templates. Pick one, then change it to fit how you work. You can also describe any job in your own words.

The main features

Rakazo is more than a chatbot. These are the features that make a bot useful day to day.

  1. Connects to your apps. Gmail, GitHub, Notion, Slack, Google Calendar and more. The official docs list 1,400+ apps.
  2. Remembers what it learns. Tell a bot once that you prefer short replies, and it keeps that in memory.
  3. Works on a schedule. A bot can start on a timer, when an email arrives, when a GitHub issue opens, or from a webhook.

Learns by watching

Show a bot a task once on its computer, and it saves the steps as a reusable skill.

Teamwork

Bots can hand work to each other and chat together in groups.

Calls and meetings

A bot can call you in the app, or join Zoom and Google Meet to take a transcript.

Pages

Bots build live dashboards and documents you can open full screen and share by link.

You stay in control

Because you run Rakazo, you decide which AI it uses and what it's allowed to do without asking.

  1. Choose any AI model. Each bot can use a different one, so a cheap model can sort email while a stronger one writes reports.
  2. You approve risky actions. Pick which actions need your OK. The bot pauses and shows Approve and Deny buttons.
  3. Claude, ChatGPT, Grok or a free local model. Use a subscription you already have, an API key, or Ollama and LM Studio on your own machine.

Where you can use it

All the apps talk to the same Rakazo server, so your bots and chats follow you from your laptop to your phone.

You can also talk to bots from the chat apps you already use.

  1. Chat from Slack, Teams, WhatsApp, Telegram or iMessage. WhatsApp, Telegram and iMessage need the self-hosted version.
  2. @mention a bot to hand it work. It replies in the same thread, like a teammate would.

Is Rakazo free?

The Rakazo software is free. What you may pay for depends on how you set it up.

A server needs about 2 CPU cores and 4 GB of memory, per the official README.

Who Rakazo is for

A good fit if you…

  • Want AI help with real tasks like email, research or reports, not just answers
  • Care about privacy and want your data on your own machine
  • Already pay for Claude or ChatGPT and want more out of it
  • Want to try different AI models without switching apps

Maybe not yet if you…

  • Only need a quick chatbot for questions
  • Don't want to install anything (try the hosted version instead)
  • Need a finished product with no rough edges. Rakazo is young and changes every day.

How to get started

There are two ways to start. Pick the one that matches how hands-on you want to be.

Easiest

Use the hosted version

  1. Go to app.rakazo.com and create an account.
  2. Rakazo creates your first bot, called Chief.
  3. Tell Chief its job in plain words. It asks for anything else it needs.
Free

Run it yourself

  1. Install Docker on your computer.
  2. Run the one-line installer from the install steps.
  3. Open http://127.0.0.1:5173, create an account and connect a model.
  1. First steps. The official docs use the same three steps: sign in, meet Chief, then give it a job.
  2. Hosted version starts here. The blue Get started button opens the sign-up page.

FAQ

Is Rakazo free?

The software is free and open source under the Apache-2.0 license. You only pay for the AI model you connect, unless you use a free local model, and for a server if you choose to run it on one.

Do I need to know how to code?

No. You talk to bots in plain words. Running it yourself means copying one install command and having Docker installed. Our step-by-step install guides are on the way.

Is Rakazo safe?

Each bot works inside its own sandboxed computer, and you decide which actions need your approval. When you self-host, your data stays on your machine or server.

Which AI model should I use?

If you already pay for Claude Pro or Max or an eligible ChatGPT plan, sign in with it. Otherwise use an API key from a provider such as OpenRouter, or run a free local model with Ollama or LM Studio.

Is it spelled Rakazo, Rakazoo or Rakazzo?

The correct name is Rakazo, with one "z" and one "o" at the end.

Is rakazo.org the official Rakazo website?

No. rakazo.org is an independent beginner's guide. The official site is rakazo.com and the source code is at github.com/elie222/rakazo.
